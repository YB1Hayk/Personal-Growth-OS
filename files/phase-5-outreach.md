# Фаза 5 — Outreach менеджер

Цель: платформа генерирует персонализированные офферы и рассылает их лидам, я вижу воронку.

---

## Бэкенд

- [ ] `outreach.router.ts`, `outreach.controller.ts`, `outreach.service.ts`, `outreach.repository.ts`
- [ ] Эндпоинты:
  - [ ] `GET /api/projects/:id/outreach` — статистика воронки
  - [ ] `POST /api/projects/:id/outreach/campaign` — создать рассылку
  - [ ] `GET /api/projects/:id/outreach/logs` — история касаний
  - [ ] `PUT /api/outreach/:id/status` — обновить статус лида в воронке

---

## Генерация офферов

- [ ] Системный промт "Оффер-писатель" в `AgentPrompt` (температура 0.3)
- [ ] Claude генерирует оффер на основе: профиля лида + `project_context` + боли
- [ ] A/B тест: 2 варианта оффера, система трекает который работает лучше
- [ ] Автооптимизация: со временем склоняется к более конверсионному варианту

---

## Каналы рассылки

**Telegram DM:**
- [ ] Отправка через Telethon (аккаунт из проекта)
- [ ] Rate limiting: не более N сообщений в час (настраивается)
- [ ] Трекинг: отправлено / получен ответ

**Email (SendGrid):**
- [ ] Интеграция SendGrid API
- [ ] HTML шаблон письма
- [ ] Трекинг открытий через SendGrid webhooks

---

## Очередь рассылок (Bull)

- [ ] Джоб `send-outreach`: отправка одного сообщения
- [ ] Джоб `process-campaign`: разбивает кампанию на отдельные джобы с задержкой
- [ ] Уважение rate limits платформ

---

## Воронка

Статусы лида: `new` → `contacted` → `opened` → `replied` → `interested` → `call_scheduled` → `closed`

- [ ] Автоматическое обновление статуса при событиях (ответил → `replied`)
- [ ] Отображение воронки в дашборде (Kanban или funnel chart)

---

## Фронтенд

- [ ] Страница "Outreach"
- [ ] Воронка: колонки по статусам, карточки лидов
- [ ] Кнопка "Новая кампания" → выбор лидов + канал + генерация офферов
- [ ] Превью офферов перед отправкой (с возможностью редактировать)
- [ ] Статистика: sent / open rate / reply rate
- [ ] Редактор системного промта для оффер-агента

---

## Критерий готовности фазы
Выбираю 10 лидов → платформа генерирует персональные офферы → апрувлю → рассылка уходит → вижу кто ответил.
