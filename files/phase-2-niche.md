# Фаза 2 — Нишевой менеджер

Цель: могу создать проект, указать нишу и контекст, подключить аккаунты. Это основа для всех остальных модулей.

---

## Бэкенд

- [ ] `projects.router.ts` — маршруты CRUD
- [ ] `projects.controller.ts`
- [ ] `projects.service.ts`
- [ ] `projects.repository.ts`
- [ ] `projects.schema.ts` — Zod валидация
- [ ] Эндпоинты:
  - [ ] `GET /api/projects` — список проектов
  - [ ] `POST /api/projects` — создать проект
  - [ ] `GET /api/projects/:id` — один проект
  - [ ] `PUT /api/projects/:id` — обновить
  - [ ] `DELETE /api/projects/:id` — удалить
- [ ] То же самое для `accounts` (подключённые аккаунты TG/IG/Threads):
  - [ ] `GET /api/projects/:id/accounts`
  - [ ] `POST /api/projects/:id/accounts`
  - [ ] `DELETE /api/projects/:id/accounts/:accountId`
