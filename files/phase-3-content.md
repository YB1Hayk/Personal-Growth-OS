# Фаза 3 — Контент движок

Цель: платформа генерирует посты через Claude и публикует их по расписанию.

---

## Бэкенд

- [ ] Настроить Claude API клиент (`shared/lib/claude.ts`)
- [ ] `content.service.ts` — генерация поста под каждую платформу
- [ ] Системный промт для контента в таблице `AgentPrompt` (температура 0.8)
- [ ] `content.repository.ts` — CRUD для `ContentPost`
- [ ] Эндпоинты:
  - [ ] `GET /api/projects/:id/posts` — очередь постов
  - [ ] `POST /api/projects/:id/posts/generate` — сгенерировать пост
  - [ ] `PUT /api/posts/:id/approve` — апрувнуть пост
  - [ ] `PUT /api/posts/:id/schedule` — поставить в расписание
  - [ ] `DELETE /api/posts/:id` — удалить
