# Фаза 4 — Лидогенератор

Цель: платформа собирает базу потенциальных клиентов из разных источников в единую таблицу.

---

## Бэкенд

- [ ] `leads.router.ts`, `leads.controller.ts`, `leads.service.ts`, `leads.repository.ts`
- [ ] Эндпоинты:
  - [ ] `GET /api/projects/:id/leads` — список лидов (фильтры: статус, источник, теги)
  - [ ] `POST /api/projects/:id/leads` — добавить вручную
  - [ ] `PUT /api/leads/:id` — обновить статус/теги
  - [ ] `DELETE /api/leads/:id` — удалить
  - [ ] `POST /api/projects/:id/leads/parse` — запустить парсинг

---

## Источники лидов

**Telegram (первый приоритет):**
- [ ] Интеграция Telethon через Python микросервис или n8n
- [ ] Парсинг участников Telegram-канала по username/ссылке
- [ ] Сохранение: username, имя, bio, ссылка на профиль

**Apollo.io (LinkedIn):**
- [ ] Интеграция Apollo.io API
- [ ] Поиск по должности + компании + нише
- [ ] Сохранение: имя, должность, компания, email, LinkedIn URL

**Hunter.io (email по сайту):**
- [ ] Интеграция Hunter.io API
- [ ] Поиск email по домену компании
- [ ] Обогащение существующих лидов

---

## Обогащение лидов

- [ ] Claude анализирует профиль лида и добавляет: боли, релевантность для ниши, рекомендуемый подход
- [ ] Скоринг лида (0-100) на основе соответствия ICP

---

## Фронтенд

- [ ] Страница "Лиды" — таблица со всеми лидами
- [ ] Фильтры: по источнику, статусу, тегам, скорингу
- [ ] Кнопка "Запустить парсинг" → выбор источника и параметров
- [ ] Карточка лида: вся информация + история касаний
- [ ] Bulk-действия: выбрать несколько → изменить статус / добавить в рассылку
- [ ] Экспорт в CSV

---

## Критерий готовности фазы
Указываю Telegram-канал конкурента → платформа парсит участников → вижу список лидов в таблице со скорингом.
