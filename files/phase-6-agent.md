# Фаза 6 — AI Sales агент

Цель: Claude автономно ведёт первичный диалог с лидом, квалифицирует его и бронирует созвон.

---

## Бэкенд

- [ ] `agent.router.ts`, `agent.controller.ts`, `agent.service.ts`, `agent.repository.ts`
- [ ] Эндпоинты:
  - [ ] `POST /api/agent/webhook/telegram` — входящие сообщения из Telegram
  - [ ] `GET /api/projects/:id/conversations` — список диалогов
  - [ ] `GET /api/conversations/:id` — один диалог с историей
  - [ ] `PUT /api/conversations/:id/handoff` — передать диалог человеку

---

## Логика агента

- [ ] Системный промт "Продажник" в `AgentPrompt` (температура 0.3)
- [ ] Промт включает: `project_context`, оффер, ICP, инструкции по квалификации
- [ ] Агент ведёт диалог: отвечает на вопросы, работает с возражениями
- [ ] Квалификация лида по критериям из `project_context`
- [ ] При готовности лида: предлагает Calendly-слот
- [ ] Сохранение полной истории в таблице `Conversation`

---

## Триггер уведомления

- [ ] Когда лид переходит в статус `interested` или `call_scheduled` → push в Telegram владельцу
- [ ] Уведомление содержит: имя лида, саммари диалога (сгенерированный Claude), ссылку на разговор
- [ ] Саммари: 3-5 предложений — кто такой, что хочет, какой следующий шаг

---

## Handoff (передача человеку)

- [ ] Кнопка "Взять диалог" в дашборде
- [ ] После handoff агент перестаёт отвечать, владелец пишет сам
- [ ] Статус диалога меняется на `human_handling`

---

## Интеграция с Calendly

- [ ] Calendly API: получение доступных слотов
- [ ] Агент предлагает 2-3 конкретных времени
- [ ] При подтверждении: создание события через Calendly API
- [ ] Уведомление владельцу о забронированном созвоне

---

## Фронтенд

- [ ] Страница "Sales агент"
- [ ] Список активных диалогов: имя лида, статус, последнее сообщение, время
- [ ] Открытый диалог: переписка + кнопка "Взять диалог"
- [ ] Уведомления в дашборде о горячих лидах
- [ ] Редактор системного промта агента
- [ ] Статистика: диалогов всего / квалифицировано / созвонов забронировано

---

## Критерий готовности фазы
Лид пишет в Telegram → агент отвечает → квалифицирует → предлагает созвон → мне приходит уведомление с саммари → вижу диалог в дашборде.
