# Первый рабочий срез: проекты и задачи

В архивной копии добавлены общий экран «Сегодня», задачи с привязкой к проектам, быстрый захват наброска, разбор идей и рабочая страница проекта с целью, аудиторией, текущим фокусом и контекстом бренда. «Стратегии роста» показывают активные гипотезы по каждому проекту. Изменения находятся в этой распакованной папке; исходный ZIP и существующая база данных не изменены.

## Обновление локальной копии

Перед обновлением существующей базы остановите API и сделайте резервную копию SQLite по инструкции в `README_REVIEW.md`. Не запускайте reset.

Для новой чистой установки в терминале API:

```bash
cd apps/api
npm ci
npm run db:generate
npm run db:migrate
npm run typecheck
npm run dev
```

Для обновления существующей SQLite-базы используйте резервное копирование и процедуру `db:upgrade` из `README_REVIEW.md` вместо `db:migrate`.

В отдельном терминале веб-приложения:

```bash
cd apps/web
npm ci
npm run dev
```

Откройте адрес Vite. Новый экран «Сегодня» показывает задачи из всех проектов. Быстрый переход из карточки проекта открывает его контентный раздел; сам выбранный проект сохраняется между перезапусками браузера.

Если база новая и пустая, `db:upgrade` применит все доступные миграции без флага подтверждения резервной копии. Для существующей базы этот флаг допустим только после остановки API и создания резервной копии.

## Состав среза

- `Task`: проект, название, заметка, статус, приоритет и срок.
- `Idea`: отдельный входящий поток идей с ожидаемым эффектом, оценкой усилий, уверенностью и статусом.
- API CRUD на `/api/tasks` с проверкой входных данных.
- API `/api/ideas`; идею можно принять и атомарно превратить в задачу или отложить.
- Экран «Сегодня»: общий список, создание задачи/наброска и отметка выполнения.
- Экран «Разбор идей»: оценка целесообразности без обязательных полей у обычных задач.
- Выбор проекта запоминается в браузере.
- Рабочее пространство проекта сохраняет цель, аудиторию, текущий фокус, DNA и голос бренда.
- Экран «Стратегии роста» собирает активные гипотезы по проектам и показывает, где пока нет идей в работе.

## Результаты проверки в активной копии

- API: Prisma Client сгенерирован, `typecheck` и `build` проходят.
- Web: production `build` проходит. `lint` проходит без ошибок; остаются 6 предупреждений React Hook dependencies в `App.tsx`, `LeadManager.tsx`, `MarketAnalyzer.tsx`, `OutreachEditor.tsx`, `OutreachEngine.tsx` и `TrafficManager.tsx`.
- Все 9 SQL-миграций успешно развернулись через Prisma на отдельной временной SQLite-базе. Временные файлы после проверки удалены.
- Сквозной сценарий на временной базе проверен через Prisma: проект с текущим фокусом → идея с оценкой → принятие идеи → связанная задача в общем списке.
- Из существующего API-regression набора 14 проверок проходят. Один оставшийся исторический сценарий миграции завершается в дочернем Prisma-процессе с кодом Windows `3221226505`; он требует отдельной диагностики на этой ОС. Проверка legacy-базы, не использующая исторический `Lead.contact`, проходит отдельно.
- Реальные Telegram/AI-вызовы и браузерный UI flow в этом прогоне не выполнялись. Рабочая пользовательская база не открывалась и не изменялась.

Новая миграция добавляет таблицу `Idea` и необязательное поле `Project.currentFocus`.
